# Audio credits

Every file in this folder is released under Creative Commons Zero (CC0 1.0): free to use for anything, no attribution required. Credit is given here anyway.

- **Sound effects** (`*.wav`): from Kenney's sound packs (Impact Sounds, Interface Sounds, RPG Audio, Sci-fi Sounds, Digital Audio), https://kenney.nl. Obtained through the CC0 mirror in the npm package `@netforge/asset-library-files` 0.2.0, then converted from Ogg to mono 32 kHz WAV and normalised so they decode on every browser, including iPhones.
- **Music** (`battle_theme_a.mp3`): "Battle Theme A" by cynicmusic, https://opengameart.org/content/battle-theme-a. Re-encoded at 80 kbps.
