# CHEM 1120 Notes: Why Equilibria Shift (Q vs K)

Equilibrium is dynamic. At equilibrium the forward and reverse reactions are still happening, at equal rates, so concentrations stay constant. Constant does not mean equal: an equilibrium mixture can be 99% product or 1% product.

For aA + bB <=> cC + dD, the reaction quotient is Q = [C]^c[D]^d / [A]^a[B]^b, using whatever concentrations exist right now. K is the value Q takes at equilibrium. K depends only on temperature.

Le Chatelier's principle is a shortcut for predicting direction. The reason behind it is Q vs K:
- If Q < K, there is "too little product": the forward rate is temporarily faster, and the system shifts right until Q = K.
- If Q > K, the reverse rate wins and the system shifts left.

Adding a reactant lowers Q, so the system shifts right. K does not change.
Compressing a gas mixture (smaller volume) raises all partial pressures; Q changes if the moles of gas differ on each side, and the system shifts toward fewer moles of gas. K does not change. Adding an inert gas at constant volume changes nothing.
Changing temperature is different: it changes K itself. For an exothermic reaction, heating lowers K, so the system shifts left.
A catalyst speeds up the forward and reverse reactions equally. The system reaches equilibrium faster, but Q, K and the equilibrium position are unchanged.

Example: N2(g) + 3H2(g) <=> 2NH3(g), dH = -92 kJ. Removing NH3 lowers Q below K, so more NH3 forms. Heating lowers K, so less NH3 at equilibrium, even though the reaction gets there faster.
